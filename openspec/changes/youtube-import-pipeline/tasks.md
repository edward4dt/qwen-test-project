# Tasks: YouTube 解析匯入卡片流程

## 1. 音訊與字幕取得
- [ ] T101 用 yt-dlp 下載目標影片音訊與內建字幕（若有）
- [ ] T102 無字幕時，用 whisper.cpp（後端批次版）產生逐字稿與時間戳

## 2. 詞彙處理
- [ ] T103 用 fugashi 對逐字稿斷詞，篩出候選詞彙/句型（**已改為 plugin 架構，本檔案僅保留日文 plugin 的實作任務，其餘語言的斷詞技術選型留待階段三**）
- [ ] T104 依詞頻、難度、長度等規則過濾候選詞彙
- [ ] T105 為每個候選詞彙查詢中文/英文解釋（JMdict 離線字典 或 Jisho API）（**已改為 plugin 架構，本檔案僅保留日文 plugin 的實作任務，其餘語言的字典技術選型留待階段三**）

## 3. 音檔與卡片組裝
- [ ] T106 依時間戳用 ffmpeg 從原始音訊切出單詞/例句發音片段
- [ ] T107 整合文字、讀音、意思、音檔，輸出符合 `Card`/`Deck` 介面的 JSON（依賴 T103-T106）

## 4. API 與校對
- [ ] T108 建立 FastAPI `/api/import` 端點，採 BackgroundTasks/Queue 非同步模式：立即回傳 `task_id`，前端輪詢 `/api/task/{task_id}` 取得進度與結果
- [ ] T109 建立極簡人工校對頁面（列表顯示/編輯/刪除自動產生的卡片）
- [ ] T110 用 2-3 支實際 YouTube 影片跑完整流程，驗證卡片品質可接受

> 依賴關係備註：T106 若來源無字幕，必須等 T102 完成才能取得精確時間戳；T107 需等 T103、T104、T105、T106 皆完成。
> 完成標準：T101-T108 完成後即可讓前端串接；T109、T110 可視精力決定是否在 MVP 就做完整版。
